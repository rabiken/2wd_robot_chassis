# Balancing Robot — 3D Printable Chassis

This repository contains the 3D-printable mechanical parts for my two-wheeled self-balancing robot.

The chassis is designed as a modular structure consisting of multiple floors connected by pillars. The parts are provided as STL files for 3D printing.

## Chassis Components

The current chassis consists of:

* **Pillars — Type 1**
* **Pillars — Type 2**
* **Floor 0**
* **Floor 1**
* **Floor 2**

Tyoe 1 pillars are used to connect each floor.
Type 2 pillars are used to mount the motor drivers.

## File Structure

```text
./
└── STL/
    ├── robot_chassis-floor_0.stl
    ├── robot_chassis-floor_1.stl
    ├── robot_chassis-floor_2.stl

    └── robot_chassis-pillar_t2.stl
```

## 3D Printing

The parts are designed for FDM 3D printing. The STL files can be imported into a slicer such as PrusaSlicer for printing.

The chassis is designed to be assembled using M3 bolts and nuts.

## Assembly

The individual parts can be assembled to form the complete robot chassis.

The current design is still under development, and dimensions and components may be updated as the robot development progresses.
